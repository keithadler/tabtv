TabTV
SETTINGS

NEVER TAKE PICTURES OF THESE SITES

One hostname per line. Subdomains match too, so bank.com covers online.bank.com. Tabs on these sites show a snow screen in the guide. Private (incognito) tabs are never photographed.

SEARCH WHAT WAS ON SCREEN

Off by default. When on, TabTV also notes the words visible on the page each time it takes a picture, so typing in the guide can find a tab by what you saw there, not only its title. The words are stored next to the picture, on this computer, and go away with it. Sites on the never-list are skipped, and turning this off forgets every word already noted.

PICTURES

Pictures live only in this browser profile and are deleted seven days after a tab closes, or right away if you press this.

UNPACKED INSTALL

This copy was loaded from a folder, so it can watch manifest.json for a new version number and reload itself within 30 seconds. It never reloads while the guide is open, and a version that adds permissions still needs the reload arrow in chrome://extensions so you can approve them.

SHORTCUT

The guide opens with the shortcut set on Chrome's shortcuts page.
